简单折腾一些华生手表小机芯

自从几个月前在ebay捡到第一个破烂摆件断了的华生机芯时，短短一会工夫，专门放破烂的袋子里已经迅速出现了至少20多个类似的洋垃圾。有些是踩坑了，有些自认为是捡漏。简单聊聊折腾这些小机芯的故事。

我主要购入的是0s，3/0s，6/0s，7 ¼L这几个类别的机芯，其中前三个是早期华生手表中最常见的机芯大小—或者说我从来没见到有更大的机芯装到过手表壳中。这三款均为四瓣簧结构，带来了良好的表壳相容性和跟目前流行的瑞士设计风格有很大不同的上链结构。

从这张图可以清晰看出不同机芯的尺寸与直径对比。

前置知识：型号与等级区分

在谈论具体的机芯之前，需要了解简单的等级区分和型号区分。某些大小有不止一个型号，配件可能通用也可能不通用，所以正确的识别就是必修课。

华生的型号命名通常格式为：大小 Model.年份 Grade.等级

Model一般是一个年份，代表了此型号的推出时间。 Grade代表此机芯在这个Model之间的等级，通常有三个数字或一个单词作为名称。

某些型号推出过早，导致没有数字代号，在后来的华生灰皮书中官方补上了数字代号方便识别。

那么就要引申出一个问题：什么级别的机芯是高级的？或者是值得修复的呢？

我个人认为只要超过15钻（15J），都算不错的机芯，值得一修。

在所有Grade中： 早期最高级的是A.W.Co级别（即American Watch Co.）。 直到1900年，被Riverside Maximus级彻底取代，在此期间有个别混用表盘的成品出现。（本文只聊小机芯，所以A.W.Co就暂且不提）。

第二高级的就是名声在外的Riverside级。它至少有13种尺寸和24种不同型号。第一款Riverside机芯是8-size Model 1873女士款。Riverside这个名称至少在华生机芯中使用超过60年。此外，每个尺寸/型号类别中通常有多种款式（各种表面处理、镶嵌、钻石、防磁以及猎装或开面配置）。

Riverside可以被视作常规款中的旗舰，并且价格实惠，因此每一个华生好表壳都应配备一个Riverside级的机芯。

一、 0s机芯

那么从最大的开始聊起吧。华生主要的0s机芯分为4个大型号，分别为Model 1887，Model 1891，Model 1900和Model 1907。其中1900和1907又分为开面（Open Face）与猎装（Hunting）两个版本。

（图片来自Jerry Treiman）

最早期的0s，就是1s Model 1882的缩小版，一般存世于猎装女士怀表，手表中基本未见，所以我并没有真正上手过。

1. Model 1891

0s真正的重塑是1891年款。这个款式至少迭代了5回，并且有719钻的各种衍生版本。根据Jerry Treiman的研究，他把这五个迭代的款式按时间顺序命名为ae。

1891-A 首版，走时轮系夹板只用一个螺丝固定。

1891-B 走时轮系改为两颗螺丝固定。

1891-C 走时轮系夹板变大。据说该型号只有最初1批的Riverside Maximus使用过，随后迅速被取代。

1891-D 上链机构做出了改变。

1891-E 序列号位置改变，同时改变了表盘固定螺丝。

在具体的Grade中，最常见的是Grade Seaside，有多种配置（7J、11J、15J均有，其中7J最多见）。

7J的Grade Seaside。

维修提示：如果需要互换零件，一定要确定好型号，并且中心轮轴有钻与无钻版本是不通用的。

15J Seaside。

15J Seaside是高钻中最常见到的，特色是花式的打磨。有些型号中心轮为金合金，有些为鎏金与镍双色，可惜并未配备华生高级机芯常见的高套筒。注意摆轮边上的15 JEWELS刻字，没有这个刻字且中心轮没钻的版本，都默认为11J。

Riverside。次旗舰，与一些Lady Waltham配置相同。根据年份不同，打磨也不尽相同。相对于其他型号十分稀少。

Riverside Maximus：旗舰级，在Riverside基础上摆轮夹板盖钻换成了钻石。相当少见，在去年一年中我只见过一枚。

购买Maximus级机芯时，一定要注意表盘是否原装。出厂时表盘有且只有一种配置（如右图所示）。数字有多种变体，唯独Waltham字体不变。一定要注意字体，该字样的Logo是旗舰独占的，任何不是这样表盘的Maximus，都可以认为是某人更换了损坏的表盘，或者是当年的零售商应客户要求改变了表盘。

拆解过程

拆下全部可见的夹板，能看见机芯的轮系布局。没什么值得说的，就是最普通的怀表小三针配置。

上图为选配了实金中心轮的高配版本。正面的打磨也比没有金质中心轮的好。

拆下所有齿轮，可见四瓣簧上链结构。

此处是整个机芯最难安装的地方。有一个几乎悬空的铁丝充当弹簧，因此需要完美地卡入两个活动部件中，一不注意铁丝就会飞走。注意大钢轮的方向。发条采用部件号2220的洞尾发条。

2. Model 1900

如果说1891款还具有古典风味，那么1900款就已经非常的现代，直到华生倒闭，基本上版路就没有更改过。1900款常见于猎装女士怀表，也见于早期战壕表。

在市场上，常见的是Grade 115（15J）与7J的型号，根据年代不同，分别叫Grade Seaside和Grade 160。良心的是，无论钻数多与否，摆轮上两个正时螺丝都为实金。

Grade 115。

若是想要更高级的型号，那就是Lady Waltham和Riverside。Model 1900似乎并没有Riverside Maximus，所以旗舰级别就是Riverside。

16J Grade Lady Waltham。相比普通款式，增加了专利星星微调与金质高套筒。

上图为我的grade riverside,17J。搭载金套筒和金质中心轮。和同门小弟Model 1904 3/0s相比少了两个钻，较为寒酸，只能说是吃了定型太早的亏。在这只机芯的摆轮上，配重螺丝也使用了实金。表壳为包绿金，制造商为Fahys（Bristol系列），属于早期的枕型战壕表。

我认为Model 1900相对于1891的最大升级是释放发条更方便了，直接在正面就可以进行释放，同时游丝外桩改成了华生特有的螺丝堵子，安装极为方便。

从这代开始，引入了金属表盘。在我见过的所有产品目录中，手表有很大一部分是镭夜光表盘、夜光针。但是经过了多年，修表师傅使用怀表表盘做了替换，虽然能完美适配，但是总有不是原装的感觉（当然了出于健康原因我也推荐换掉夜光盘和针）。

拆解过程

（正面打磨）

因为大钢轮的改动，原来位于正面的上链机构都被改动到主夹板了，正面极其简洁，铺满鱼鳞纹打磨。随后出于成本原因，正面几乎都没有打磨了。

当我拆下主夹板的时候，中心轮和分轮直接爆出来了，全部散架。

钻眼也损坏了。之前看到了一个视频，那位博主拿着宝石检测笔检测，发现所有的钻无一例外都是玻璃，这有可能是比较爱坏的原因。在官方目录中，这处钻石与3/0s 1900通用，描述为蓝宝石，但实际并不能互换，应该是跟年代有关。发条零件序列号为2228。

买了库存的发条让修表师傅换上之后，一夜之间全部裂开了。如果能有白钢的发条，就换白钢的吧。

二、 3/0s机芯

最常见的3/0s机芯就是1900款，该型号经常出现在小号战壕表、女士怀表中，常见的有： Grade 300 / 310 (7J) Grade 315 (15J)

因为底钻版本多，所以很容易能找到不错的表盘和表针。

Grade 310 (7J)。

Grade 315 (15J)与一个十分标准的3/0s战壕表。

与同年推出的0s一样，没有Riverside Maximus型号，因此最高档为Riverside。

3/0s Riverside。 最少有两个版本，早期款所有金套筒均为螺丝固定，后期则升级为压入式，同时在擒纵轮处增加了盖钻。后期版本打磨逊于前期。

官方零件指南，可见许多零件是一致的。

在这一时期，官方推出了很多Art Deco风格的方表，全部使用金属表盘。

经验总结：经过实践证明，3/0s Model 1900瓷盘版与金属盘版无法互换！因为瓷盘版本正面有一圈保护表盘的金属，如果更换为金属盘，就垫高了表盘，导致无法安装。

常见的金属表盘款式。需要注意的是原装表盘底部有一部件号，如果没有，多半就是翻写的表盘。

非常垃圾的翻写表盘，注意3点钟的豁口和没有部件号。

官方手册中的一些3/0s方表。另外1900 0s和3/0s时针眼直径为1.35mm，分针为0.75mm。

三、 6/0s机芯

6/0s是华生后期的绝对主力。在二战时的那些陆军配发表中，都是6/0机芯。因为这些我没有使用过，因此没有发言权。我只能分享一下6/0s的鼻祖：Model 1898 Jewel Series（简称JS）。

这些型号均用宝石命名，按照等级从高到低如下：

  1. Diamond（钻石） = Riverside Maximus (17J)
  2. Emerald（翡翠） (21J) = Riverside (17J)
  3. Ruby（红宝石） (17J / 15J)
  4. Sapphire（蓝宝石） (15J / 9J)

这个命名很像宝石心学园的能力等级，真希望能联名，可惜华生早了100年。同期还有一些7J和15J但是没有命名，不属于JS系列。

Grade Sapphire。Logo有两种写法，右图为更老的写法，明显老款比新款做工好。

Grade Ruby。产量非常大。其中17J的款式常常出现在歌剧院怀表和14K金表之中。（顺便一提，我这枚Ruby机芯中心轮轴钻眼也碎了。）

Grade Riverside。从这个等级开始，可以选配实金轮系了，也拥有了金套筒。

Grade Emerald。在JS系列中钻数最多，是Riverside停产之后的继任者。可见打磨明显弱于Riverside，也并没有金中心轮。

Grade Diamond。JS系列最高等级。非常稀少的型号，碰见一个价格合适的必须拿下。

注意：JS系列经历了一个小改款（即1937款），改掉了四瓣簧的结构，注意不要买错了。JS系列主要结构与0s Model 1900和3/0s Model 1900基本一致，所以不放拆解了。另外一提，猎装版本与开面版表盘不一致，不能互换。

以上是官方指南。 JS系列壳型丰富，有女士手表，男士方表，歌剧院怀表等等。在这个系列中，早期金表明显多于其他。 在官方手册中同时期的型号远远多于0s。 一些表盘。

一张原装无任何氧化的库存表盘，可以用来参考。

四、 7 ¾L (7.25L / 1930s)

作为华生的两针机芯，常常出现在一些女士手表和Curvex风格的男士手表中。同样的，版本众多，生产时间长。因为定型时间晚，已经将四瓣簧结构换成了瑞士风格的经典无钥匙上链结构。

Grade Rect (7J)：最入门的型号，反而较少。如今这些低钻数机芯最好的归宿就是作为高等级机芯的零件捐赠者。

Grade Rect (15J)：带铜套筒的版本，另有不带铜套筒的版本，经常出现。

Grade 737 (17J)带铜套筒的版本，与没有套筒的版本。可见无套筒版本中心轮轴钻石采用了压入式的套筒，这在当年算是一种新技术，汉密尔顿和华生都广泛应用。说实话我更喜欢后期版本，虽然没有套筒，但是红宝石颜色更加鲜艳。

Grade 741,21J riverside。作为本型号的旗舰机芯，增加了擒纵轮盖钻，打磨也更加精致了。虽然打磨已经与之前的Riverside相比下降了很多，但是对比同期高端产品，依旧算是佼佼者。个人认为虽然打不过汉密尔顿982，但是能稳压Hamilton 980和Lord Elgin一头。 在原配表盘上会额外标出21 JEWELS字样，注意底部的部件号，代表了是原厂表盘。经过了小一个世纪的洗礼微微氧化变黄，因为没有防水性，这个品相实属难寻。

原装表盒与标签。当年的表壳种类很多，珠宝店也会混装，所以只要对期就行。表壳是Pioneer Watch Case Co制作的，质量一般，单面包金。

拆解过程

正面。已经拆下了压板簧，固定它的两个小螺丝非常紧，差点就滑丝。

拆下摆轮和摆夹板，摆轮还是十分传统的双金属温差补偿摆轮。

拆下所有夹板，依旧是很古典的传动结构。

代表旗舰身份的Riverside夹板。擒纵轮盖钻通过一个弹片和螺丝固定在夹板反面。

五、 小总结

我最近玩到的华生小机芯差不多就是这些，因为大小和款式原因，很多小机芯没有入手过，比如说8/0s、750机芯等等，这些遗漏的以后会陆陆续续补上。

我对怀表不怎么感兴趣，因此很多声名大噪的怀表机芯我注定是不可能花高价入手的，所以只能通过这些女士和手表机芯一窥华生20世纪早期的辉煌。我一直认为华生的倒闭实在可惜，作为美国工业制表先驱，没活过50年代，可能是已经燃尽了吧。也因为大规模的制造，留下了很多价格低、质量好的机芯让现在的人玩耍。

我还会继续玩华生的，虽然在国内是冷门中的冷门，卖出就亏钱，游丝软，互换性差，品牌价值没有，但只要喜欢就不需要在意这些有的没的。
